## Stops and standing answers

| What happens | Answer |
| --- | --- |
| Auto mode refuses a command | Use the answer under "Refused commands". Where that says a refusal is a stop, or names no alternative, the pass parks (approved standing answer 2). |
| An acceptance item can't be met as written, or a mechanism row proves false | The pass parks under approved standing answer 12. Write the stop under `## Stop` in `docs/STATUS.md`. |
| `npm ci` fails inside the page test because the cache is cold | Run `npm ci --prefix approval-queue` in the worktree, then the test once more. A second failure with the same cause is a stop. |
| The page test finds another process on its port, or no port from 7931 to 7999 is free | Run the test once more: it picks its port at random. If no port is free, record the `ss -ltn` output in the PR and stop. |
| A test server outlives a failed test run | Leave it running and name its process id and port in the PR's `## Decisions`. It serves a removed temporary tree and never the live queue, and its `timeout` ends it. |
| The screenshot script can't find Playwright or Chromium at the paths in `notes-common.mjs` | The screenshot is an added check. The PR says under acceptance item 5 that no screenshot was taken and why, and the served-HTML test stands as the evidence. |
| The screenshot shows the stop sentence or the label cut off, overlapped, or missing | Fix it inside `PacketPage.svelte` and the page's stylesheet, then take the screenshot again. A fix that needs another component is allowed and recorded as a `[file-list]` planning miss. |
| A task passes twice its estimate | One line in `## Decisions` with both numbers. The run goes on. |
| The run's path passes 180 minutes | The run goes on. The planner's rule parks a plan before code is written and sets no stop after it. The PR's `## Planning misses` gets one `[estimate]` line with the actual path. |
| The review ends on `escalate`, or a second read is short of `accept` | A stop, as executor rule 5 says. |
| A fix would need a dependency, `vite.config.ts`, or a file outside the lists above | Allowed when it serves an acceptance item, and recorded in `## Planning misses` with the `[file-list]` tag. A change to what an acceptance item says is a stop. |
