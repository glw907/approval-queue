## What the pass changes

The buttons A3 drew start working. A click on the document page is posted to the server at once, and the page changes only when the server says the record is on disk. A click the server can't take leaves the document open with a message saying what wasn't recorded and why, and a "Try again" button. A decided document shows Undo until the waiting session picks the decision up, and says which side of that hand-off it is on. An approve records each pull request's commit or the design's hash, and a new `merge <id>` subcommand merges an approved document's pull requests at those commits, or none of them. Nothing Geoff uses changes: the live queue on port 7907 stays the old app until A6.

4. **What the server refuses, and the status of each.** A `POST` whose `Origin` header isn't the server's own origin: 403. A content type whose media type, parsed as kit's `matches_content_type` parses it (the part before any `;`, lowercased, `http.js:65-68`), isn't `application/json`: 415, so `application/json; charset=utf-8` passes. SvelteKit's own check covers only form content types (mechanism 5), and a JSON endpoint that writes an approve, which is Geoff's merge authorization, checks the origin itself. An unknown id, the specimen pages `/d/markdown` and `/d/long` included (their load returns a waiting state, and a click there is refused with a sentence): 404. A body that isn't one of call 3's shapes, an `action` of `handed` or `withdraw`, `read` on anything but a report, `approve` or `sendback` on a report, a question id or pick the document doesn't have, and an approve whose `answers` leave a question unanswered: 400, naming what was wrong. A decide on a document that isn't waiting: 409, with the state, except call 5's repeats. An `answer` post on a document that isn't waiting: 409. An Undo on a waiting document whose last record isn't an `undo`, so there's nothing to undo: 409. A merge document with no `heads.json`: 409 (call 8). A store read or write that throws: 500 with the error's message. Each refusal carries a sentence from `strings.ts` the page shows as the "why".
5. **A repeat is answered, never written twice.** A decide that arrives when the fold already says decided with the same action, or an Undo that arrives when the fold already says waiting with an `undo` as the last record, writes nothing and answers 200 with the state.
